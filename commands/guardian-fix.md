Invoke the `guardian-bugfix` skill to find and fix implementation bugs in the current codebase.

Focus areas: race conditions, null/undefined safety, edge cases, off-by-one, memory leaks, missing or swallowed error handling, broken happy paths.

The skill must explain *why* each finding is a bug and propose a fix the user can approve before it is applied.
